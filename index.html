Resumable file upload

Pick a large file and start the upload. Pause it, cut the connection, or even close the tab: the upload continues from where it stopped instead of starting over.

Connection

The token is kept in memory only and is never saved. Smaller chunks make the offsets move in visible steps during a demo.
